
# Server Log Analysis using Python and Jenkins CI/CD

## Introduction
This project analyzes server log files using Python and
automates the process using Jenkins CI/CD.

## Objectives
- Read server log files.
- Identify INFO, WARNING, ERROR and CRITICAL messages.
- Detect important server errors.
- Perform automated testing.
- Automate execution using Jenkins Pipeline.

## Technologies Used
- Python
- Jenkins
- Git
- GitHub
- Visual Studio Code

## How to Run

Run the application:

python app.py

Run automated tests:

python -m unittest discover -s tests -v

## Expected Output
The application displays the count of each log level
and identifies ERROR and CRITICAL messages.

## Conclusion
The project demonstrates automated server log analysis
and testing through a Jenkins CI/CD pipeline.
